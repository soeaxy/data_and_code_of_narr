# Uranium Mineral Prospectivity Modeling – Husab Deposit, Namibia

This repository provides a **reproducible and open-source implementation** of the workflow used in the study:

> **“Integrating Cost-sensitive Ensemble Learning and Geoscience Big Data for Uranium Prospectivity Mapping in the Husab Uranium Deposit, Namibia.”**

The workflow integrates **sample balancing**, **cost-sensitive ensemble learning**, and **SHAP-based explainable AI** to predict uranium mineralization potential at 20 m spatial resolution.
